# **App Name**: Arogya CRM

## Core Features:

- Role-Based Authentication: Secure access based on user roles (admin, sales_team_lead, sales_executive, marketer, support) using Firebase Authentication with custom claims.
- Teamspaces: Implement Teamspaces to isolate data and modules for different teams (Sales, Marketing, Support, Operations) using Firestore.
- Lead Management: Create, import (CSV), and manage leads with webform capture, Facebook Lead Sync (placeholder API), Google Ads attribution, lead scoring, source, status tracking, duplicate detection, assignment logic, and activity timeline.
- Sales Pipeline: Visualize and manage deals through a Kanban board with stages: New, Contacted, Qualified, Demo, Negotiation, Won, Lost.
- Analytics Dashboard: Display key metrics such as total revenue, conversion rate, leads per source, campaign ROI, and sales performance using Recharts.
- Inventory Management: Manage products, track stock levels, handle orders, generate invoices, and track refunds.
- AI Lead Scoring: Tool to automatically rank the best leads in the Sales pipeline, to help the user focus their attention, based on a Machine Learning model.

## Style Guidelines:

- Primary color: Herbal Green (#4CAF50) to reflect the Ayurvedic theme.
- Accent color: Gold (#FFD700) for highlighting important elements and calls to action.
- Background color: Light Green (#F0F4F0) providing a clean, minimal look.
- Body and headline font: 'Inter', a sans-serif, for a modern and neutral look.
- Fixed left sidebar with a top search bar and module-based page views for a Zoho CRM-inspired layout.
- Use consistent and relevant icons from libraries like FontAwesome or Material Icons.
- Smooth transitions and subtle animations on page loads and interactions to enhance user experience.
